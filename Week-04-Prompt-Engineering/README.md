# Week 4 — Prompt Engineering

> **Transparency note:** These are practice exercises documented now. Do not represent them as official Xtragrad assignments or as work completed on earlier dates unless that is accurate. If Google Classroom provides exact challenge instructions, follow those first.

## Objectives
- Compare vague and structured prompts.
- Generate a study plan under explicit constraints.
- Analyze a fictional resume without inventing qualifications.
- Generate and validate multiple-choice questions.
- Evaluate outputs rather than assuming they are correct.

## Challenges
1. [Prompt Comparison](challenges/challenge-01-prompt-comparison.md)
2. [AI Study Assistant](challenges/challenge-02-study-assistant.md)
3. [Resume Analyzer](challenges/challenge-03-resume-analyzer.md)
4. [Quiz Generator and Validation](challenges/challenge-04-quiz-generator.md)

## Method
Define the task, provide context, specify output format and constraints, generate a response, evaluate it, refine the prompt if needed, and record the result.

## Evidence
The Markdown reports contain prompts, illustrative outputs, and evaluations. Add genuine screenshots to `evidence/` if required. Do not label illustrative material as a screenshot of an interaction that did not occur.

## Learning Outcomes
These exercises demonstrate structured prompt design, constraint setting, iterative refinement, and critical evaluation of AI-generated content. A well-written prompt improves controllability but does not guarantee factual correctness.
